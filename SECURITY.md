# Security and sensitive-data policy

This is an active native-port development repository, not a hosted service.

## Do not publish sensitive material

Never include pairing profiles, authentication keys, device configuration, retail assets, save data, raw crash dumps, arbitrary memory, personal screenshots/videos, or private IP/network details in an issue, pull request, commit, or build artifact.

Use the project's existing sanitised evidence format for crash and runtime discussion. A screenshot/video is not automatically safe to publish merely because it came from the target device.

## Reporting

For a vulnerability in repository code, build tooling, or a project-managed Vita helper, contact the repository owner privately through GitHub before opening a public issue. Provide a minimal reproduction and omit secrets and user data.

Do not report an unrelated Vita firmware, taiHEN, VitaShell, VitaCompanion, VitaSDK, FFmpeg, or upstream Renegade vulnerability here; use that project's reporting channel.

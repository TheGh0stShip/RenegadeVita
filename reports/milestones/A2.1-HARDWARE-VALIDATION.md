# A2.1 Physical Hardware Validation

Status: **ACCEPTED — PASS**

Validation date reported by the hardware tester: 2026-08-07.

## Purpose

A2.1 extended the known-good native Vita source-port bootstrap through the
original Westwood filesystem and MIX/archive architecture. It proved on ARM
hardware that unchanged retail data can be opened through original engine
factories, exposed as a biased original `FileClass`, and read without a custom
runtime archive parser or converted assets.

## Architecture and source identity

- Native PS Vita ARM executable/VPK built by Bash, CMake, Ninja, and VitaSDK.
- Official EA `CnC_Renegade` revision
  `3e00c3a1b97381bb28be89a35b856375e0629a08`.
- Canonical upstream remained pristine; generated staging received explicit
  patches with `patch --batch --forward --fuzz=0 --no-backup-if-mismatch`.
- Original retail files were used unchanged under
  `ux0:data/renegade/retail/Data/`; no retail data was packaged or copied.
- Centralized Vita path translation maps Windows-style logical paths, rejects
  traversal, resolves case differences, and routes writes outside retail.
- Original archive path:
  `FileFactoryListClass -> MixFileFactoryClass -> FileFactoryClass ->`
  `BufferedFileClass -> RawFileClass -> RawFileClass::Bias`.
- The Vita adapter resolves the physical filename before the MIX layer applies
  `Bias`; it never resets the biased file afterward.

## Acceptance and future constraints

All A2.1 host, build, packaging, and physical-hardware criteria pass. A2.1 is
the known-good filesystem/MIX regression baseline for A2.2 and later.

Future work must preserve the A2.0 19/19 and A2.1 10/10 fingerprints, original
MIX biased-file semantics, centralized immutable-retail path routing, exact
zero-fuzz staging, and the original engine architecture. A2.1 deliberately did
not implement original W3D loading, WW3D asset/prototype/RenderObj systems,
scene/camera traversal, a Vita renderer backend, Commando startup, world
loading, or gameplay. Those are active A2.2 work, not reasons to replace the
engine with a custom viewer.

# Dev146: M13 death ownership and aggregate effect lookup

Full-port only: generated WWUI resources now include original death and failure option dialogs (IDs 196/197); the combat callback calls original `cGod::Star_Killed` after observation, and the Vita runtime pumps the death popup instead of immediately leaving Combat for `Loading`. A development-only, one-shot M13 lethal-damage marker is available for isolated testing after the authored intro releases the camera. The demo profile is unchanged. Death popup, Restart/Load, and failure flow have **not** passed runtime verification: the 240-second Vita3K death run reached only frame 240, before the trigger.

The user-reported Vita3K console flood was traced to original `AggregateDefClass::Load_Assets`: its Windows current-directory `GetFileAttributes` probe became `app0:/\\e_*.w3d` and bypassed retail/MIX lookup. The full-port branch now hands the original logical `.w3d` name to `WW3DAssetManager::Load_3D_Assets`, retaining the original asset manager and factory search. Deterministic zero-fuzz staging passed. In isolated M13 direct-entry Vita3K evidence, explicit `app0:/\\e_*.w3d` missing-file errors fell from 96 in the pre-fix run to 0 in `campaign-dev146-agg-direct-m13-3/`; original intro camera creation still passed. The Vita3K install-only trials `-1` and `-2` did not launch the game and are excluded from this comparison.

This is a correctness fix, **not** an audio/performance pass. At frame 120 the pre-fix emulator run recorded 11.587 average FPS, 47.889 ms simulation and 38.406 ms render-submission CPU per frame; the post-fix run recorded 4.840 average FPS, 110.101 ms simulation and 96.479 ms render-submission CPU per frame. At frame 240 the post-fix run recorded 6.122 FPS. Content and startup timing are not fixed-replay equivalent, and more original assets/meshes resolved after the fix. The original audio stream advanced in wall time while the authored cinematic advanced much more slowly, consistent with the reported heavy desync; the exact causal split remains open. Do not use CPU graphics-call time as GPU time.

Evidence: 16 focused host tests passed, original WWUI RC equivalence passed (25 dialogs/324 controls), ARM diagnostic and public builds/package passed. Diagnostic SELF SHA-256 `32ff2b941605894bca5499b82598196d7446698bec4bd3b1b56019be2c92c712` stayed in isolated Vita3K only. No physical Vita acceptance, normal campaign progression, objectives, death recovery, or audio sync pass is claimed.

# Dev145: original M13 cinematic object factory

The M13 intro script was running its timed letterbox and audio commands, but `Commands->Create_Object("Generic_Cinematic")` returned null. Slot 0 remained empty, so `Control_Camera` did not hide HUD or take the camera. The original retail `always.dbs` contains the preset, but the full-port executable omitted `combat/cinematicgameobj.cpp`, which registers its definition/persist factories. The full-port profile now links that original unit; the demo source set is unchanged. Non-M00 full-port missions no longer run the M00-specific eager presentation prewarm.

Evidence: deterministic 185-patch staging pass, ARM ELF/SELF/VPK build, `nm` confirms `_CinematicGameObjDefDefFactory`, and the asset-free public VPK SHA-256 is `d8ee6b6c826965c72511a4426b80909182825d640af750ff0322059af62dad9a`. An isolated Vita3K diagnostic direct-entry M13 run reports `Generic_Cinematic` definition valid, slot-0 object created, camera host active, HUD disabled. Captures under managed AppData `campaign-dev145-factory-direct-m13-1/` show changing original cinematic viewpoints; a later capture shows letterbox removed and first-person HUD/weapon restored. This is not normal New Game progression or physical Vita acceptance. All M13 objectives remain unverified.

Performance is not accepted: the Vita3K window reported roughly 11-14 FPS during sampled cinematic/gameplay captures, and the user observed audio falling behind. These emulator readings are not physical Vita measurements. Profile this fixed M13 intro after correctness blockers, separating simulation, render submission, backend, and audio timing.

Separate reported blocker: on player death, the Vita completion observer currently replaces the original `CombatGameMiscHandlerClass::Star_Killed` callback with a latch-only handler, and the direct runtime breaks out of gameplay on that latch. Original `cGod::Star_Killed` and its death-options dialog are therefore bypassed. The next fix must restore original death ownership, include retail death/failure dialogs, and test restart/load with isolated saves.

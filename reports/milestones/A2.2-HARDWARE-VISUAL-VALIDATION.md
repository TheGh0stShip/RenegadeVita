## Purpose and acceptance

A2.2 proved the first end-to-end physical visual path from unchanged retail
Renegade data through original Westwood filesystem, archive, W3D asset,
prototype, render-object, scene, camera, and mesh traversal code into the thin
Vita graphics backend. The genuine retail `DSP_O2TANK` object was visibly
displayed on a physical Vita. Photographic/visual evidence exists, and the
complete persistent hardware log is retained in the immutable baseline.

This is the known-good native Vita visual regression baseline. A3.x must keep
this architecture operational while moving into original Commando/Combat
startup and real world loading. A2.2 is not a replacement viewer architecture
and is not the endpoint of the port.

## Architecture proven on hardware

```text
unchanged Data/always.dat
  -> original FileFactoryListClass
  -> original MixFileFactoryClass / biased RawFileClass
  -> original ChunkLoadClass
  -> original WW3DAssetManager and prototype loaders
  -> original RenderObj/HLOD/MeshModel/material/hierarchy structures
  -> original SimpleScene/Camera/WW3D traversal
  -> original MeshClass submission boundary
  -> thin Vita renderer
  -> vitaGL / SceGxm
  -> physical Vita display
```

No custom MIX parser, custom W3D parser, converted model, replacement asset
manager, replacement scene graph, manual vertex extraction, or retail asset
conversion performed the accepted test. Retail data remained outside the VPK
and was read unchanged from `ux0:data/renegade/retail/Data/`.

- first-submission `glGetError`: `00000000`;
- unsupported submissions: **23**, exactly one per rendered frame.

The one-per-frame unsupported submission does not invalidate A2.2. It is a
bounded follow-up diagnostic: identify the original object/state/operation
once, classify it, and defer it if it does not block original world startup.

Post-acceptance diagnosis identified it exactly as
`DSP_O2TANK.BOUNDINGBOX`, class 27/OBBOX. The accepted boundary counted the
object before Westwood's default-zero collision-box display-mask guard, so it
was a diagnostic false-positive rather than a missing draw. The active exact
boundary patch now preserves that original guard and reports
`unsupported=0` with identical host mesh totals and checksum `5704AB7D`.
The immutable physical 23/23 count remains part of the accepted build's
evidence. See `reports/A22_UNSUPPORTED_SUBMISSION_ANALYSIS.md`.

## Source integration and reproducibility

The accepted native target compiled **105 original EA/Westwood translation
units** plus nine Vita port/validation C++ translation units. The original
cluster comprised wwbitpack, wwutil, wwlib filesystem/archive support, WWMath,
wwsaveload persistence core, Combat `FileFactoryListClass`, and the coherent
52-TU ww3d2 asset/RenderObj/Scene/Camera path. The exact source manifest is
retained as `source/cmake/A22OriginalSources.cmake` in the baseline.

Canonical construction and validation used:

```bash
bash ./tools/build.sh
```

All staged source changes were explicit patches applied with:

```text
patch --batch --forward --fuzz=0 --no-backup-if-mismatch
```

The canonical upstream checkout was pristine and pinned to the revision above;
no `.orig` or `.rej` files remained. The exact accepted patch set and a compact
snapshot of the port/build boundary are retained in `baselines/A2.2/`.

## Deliberately incomplete at A2.2

A2.2 did not claim Commando/Combat startup, definition/database loading,
PhysicsScene population, real level loading, textures at final fidelity,
audio, UI, networking, or gameplay. It deliberately used the isolated retail
`DSP_O2TANK` proof to validate the original visual object pipeline. The next
milestone must retire that isolated proof as the primary runtime and push into
original Commando/Combat world loading. Renderer features should be added only
as those real world call paths demand them.

## Acceptance decision

**A2.2 PHYSICAL VISUAL VALIDATION: PASS.**

The physical counts prove that all eight original meshes traversed every one
of the 23 rendered frames. This baseline is permanent and must not be
overwritten by A3.x work.

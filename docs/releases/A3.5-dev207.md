# A3.5-dev207: M13 zero-distance path correction

**Archived experimental build, published for testing and comparison.**

Selected as GitHub's Latest release to replace the outdated Dev142 listing.
That designation does not mean stable, fully playable or physically accepted.

Corrects a reproduced zero-distance AI path failure affecting M13 engineers. Two 600-frame host save replays kept both engineers finite; targeted M01 host routes also passed. Fast ARM packaging and Vita3K installation/readback passed. Dev207 was not launched in Vita3K or tested on physical hardware. Saved-state teardown leaks remained in this package.

## Limitations

M13/M01 freezes, cinematic audio sync, performance spikes and complete campaign
progression are not verified fixed. Back up your saves before testing. Issue #1
remains open. These packages predate the newer sorting, animation, ownership
and audio fixes in the current source checkpoint; no such fixes are claimed
for this binary. No new gameplay capture accompanies this publication.

Campaign and multiplayer progress

The source tree has advanced beyond the Dev207 download. Work has addressed invalid AI paths, animation sampling, saved-object ownership, rendering of sorted effects, and reproduced audio cleanup defects. Several changes passed focused host checks; the newest audio fixes remain uncompiled and untested. These later changes are not included in Dev207.

M13/M01 freezes, cinematic audio synchronization, performance spikes, and complete mission progression remain open. Save/load has passed specific tests across Vita3K and PSTV, while a reporter's failure to create a save is still being investigated. Issue #1 remains open; neither a successful compile nor an isolated successful run proves every reported problem is fixed.
